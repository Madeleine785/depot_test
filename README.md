
# Gestion de notes (Python)

## Contexte
Projet réalisé dans le cadre du TP d'autonomie a l'epf', pour apprendre à utiliser
Git et GitHub afin de suivre l'évolution d'un projet informatique.

## Objectifs
- Développer un programme Python de gestion de notes
- Enregistrer chaque étape du dévelopement avec Git
- Publier et documenter le projet sur GitHub

## Fonctionnalités réalisées
- Saisie d'un nombre de notes choisi par l'utilisateur
- Calcul de la moyenne, de la note minimale et maximale
- Contrôle des saisie(texte refusé, notes entre 0 et 20)
- Menu principal pour naviguer dans le programme

## Technologies utilisées
- Python 3
- Spyder
- Git, Git Bash et GitHub

## Lancer le programme
Ouvrir main.py dans Spyder et appuyer sur F5 (ou `python main.py` dans un terminal).
